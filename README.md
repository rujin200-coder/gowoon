## 파일

- `index.html` — 종합 홍보 웹앱 (5대 강점 탭, 공사비 절감 팁, 상담 문자 연결, vCard 저장, 주소·지도·공유)
- `kgh.html` — 김기현 대표 한옥 전문 페이지
- `fp.html` — 한화생명 법인전문 FP 디지털 명함
- `gowoon_hero.jpg` — 히어로 이미지 (현대 건축물과 크레인으로 들어 올린 모듈러 유닛, 설계 도면이 겹쳐진 장면)
- `gowoon_plan.jpg` — 세움터·대관 섹션 이미지 (평면도·배치도)
- `gowoon_modular.jpg` — 모듈러주택 섹션 이미지
- `gowoon_og.png` — 카톡·SNS 공유 썸네일 (1200×630)
